# L4: visuals

L4 builds finished visual output. The L3 write-up is the story source; if none exists this session, draft its §1 items 1–5 privately first.

## What to build
Do not ask which one unless the request is truly ambiguous. Pick by what the user said:
| User says | Build | Open |
|---|---|---|
| "L4", "visualise", "interactive", "show me" (default) | the best-fit visual page: **explore** if a parameter changes the answer, **story** for a few plots that each make one point, **study** for a topic that is mostly ideas | `viz.md` |
| "step by step calculation", "show the maths", "calc" | **calc** page: a small table changing cell by cell | `viz.md` |
| "workflow", "pipeline", "how the experiment works", "walk" | **walk** page: the biological or lab process, molecule to data table | `viz.md` |
| "deck", "cards", "flashcards", "quiz cards", "facts", "transfer", "angles" | **card deck**: facts, different angles, transfer to new settings, quiz | `outputs/deck.md` |
