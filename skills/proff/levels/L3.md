# L3 — the full lesson and deck

L3 is the deep version. Cover every part the reader needs. Use short sentences; leave nothing important out.
Paths are relative to this skill's folder.

## 1. Plan the visuals first
One question per visual. Pick as many visuals as the topic needs:
- Change over time → `svg` with `steps`.
- Calculation → `calc`, one line per step.
- Shape or spread → `svg`.
- Linear process → `flow`.
- Branches or loops → `mermaid` (trial).
- A parameter that changes the answer → `sim`.
Statistics, biology, or ML topic → read the matching `ref/ideas/*.md` once; two if the topic spans both.
These are examples, not limits. Invent the best visual. Do not draw decoration.

## 2. The chat write-up
Use these sections in order. Skip only what does not apply.
1. **Answer** — 2–4 sentences.
2. **What you need first** — 2–5 ideas: `term — plain meaning`.
3. **How it works** — the mechanism step by step. Add diagrams as needed, as in `levels/L2.md`.
4. **Worked example** — real numbers, every step, units kept. Equations as $$..$$, then a “where” line defining every symbol.
5. **Where it breaks** — assumptions and cases where the idea fails.
6. **Exam angles** — 4–6 unexpected questions with short answers. Try reversed cause/result, an edge case, changed numbers, confusable terms, design/data reading, or “why not X?”.
7. **Do not confuse** — table: term · means · not the same as.
8. **Read next** — 3–5 search terms with what each teaches. Name sources from memory only when certain they exist; mark “from memory, not opened”. DOI, page, or figure details require sources opened this session.
9. **Claim block** for science (see `SKILL.md`).
