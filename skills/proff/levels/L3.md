# L3 — full lesson: text, diagram, interactive deck, one image

You write a small JSON spec. The scripts turn it into the deck. **Never write or read the CSS or JS.**
Paths below are relative to this skill's folder (the folder with `SKILL.md`).

## Steps
1. In chat: STE answer (~150 words), one diagram (as in `levels/L2.md`), the Claim block if it is science.
2. Write `spec.json` (schema below) in the user's working folder, or a `proff/<topic>/` folder there. 7–10 slides.
3. Image (optional, one per lesson): follow `ref/image.md`. No image tool → use an `svg` or `flow` slide instead.
4. Render and check:
   ```
   python3 scripts/render.py spec.json -o deck.html --embed
   python3 scripts/snap.py deck.html      # needs playwright; skip if missing
   ```
   `snap.py` prints `WARN slide k ...` for text that spills or is clipped. Fix the spec (shorter text, fewer cards), re-render. Look at `snaps/sheet.png` once.
5. Tell the user the path to `deck.html`. Arrows or swipe to move; `--layout page` gives a scrolling page instead.
6. Offer: `→ quiz me · guide me`

## Spec
```json
{"title": "The Bootstrap", "palette": "aurora", "slides": [ ... ]}
```
Text fields accept `**bold**`, `*italic*`, `` `code` ``, blank line = new paragraph, `- ` lines = list.
Any slide may add `title`, `eyebrow` (small label), `hand` (a short handwritten aside, lowercase).

| type | fields | use for |
|---|---|---|
| `title` | `title`, `subtitle`, `hook` | slide 1 |
| `predict` | `q`, `options[]`, `answer` (0-based index), `why` | slide 2: predict before teaching |
| `text` | `t` | the problem, a definition (≤ 70 words) |
| `statement` | `text`, `color` | one big sentence |
| `notes` | `notes[]` of `{h, t, icon}` | 2–4 key concepts |
| `flow` | `steps[]` of `{h, t}` | a mechanism in 3–5 steps |
| `compare` | `a {h,t}`, `b {h,t}`, `vs` | works vs fails, A vs B |
| `image` | `src`, `caption`, `notes[]` | the mental-model image |
| `svg` | `svg` (raw inline SVG), `notes[]` | a hand-made diagram |
| `sim` | `controls[]`, `js`, `text`, `reseed` | the interactive simulation |
| `quiz` | `cards[]` of `{q, a}` | 2–3 flip cards |
| `takeaway` | `points[]`, `caveat`, `next` | last slide |

Good order: title → predict → text → flow → image → sim → compare → quiz → takeaway.

## Simulation (`sim`)
- `controls`: `[{"name":"n","label":"cells (n)","min":5,"max":200,"step":5,"value":40}]`
- `js` is the body of `function(ctx, p, W, H, rng, T)`:
  - `p.<name>` = slider values; `W`, `H` = canvas size; `rng()` = seeded random in [0,1) (the reseed button changes the seed).
  - Colours: `T.ink`, `T.muted`, `T.grid`, `T.bg`, accents `T.c[0..5]`. Font is preset.
- Draw one clear picture that changes when a slider moves. Label axes and show one live number.
- Keep the loop small enough to redraw fast (≤ ~10⁶ operations).

## Size rules
- Title ≤ 6 words. Card text ≤ 30 words. Max 4 notes, 5 flow steps, 3 quiz cards, 5 takeaway points.
- Numbers and formulas go on slides, not in the image.

Full worked example: `examples/bootstrap.json` (renders as is).
