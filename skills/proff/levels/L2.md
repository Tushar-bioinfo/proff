# L2 — diagrams plus the key concepts

1. **Predict first.** Ask one prediction question about the concept. In a chat, show it first, then give the answer below a line, so the user can think before reading on. (This is not a mode. Do not wait.)
2. **Answer** in 2–4 STE sentences.
3. **Diagrams: as many as the topic needs (usually 1–3).** One diagram per separate idea, for example the mechanism, then the calculation. Choose the form that shows the mechanism, not decoration:
   - Mermaid (`flowchart LR`, `sequenceDiagram`) where it renders (claude.ai, ChatGPT, GitHub, most IDEs).
   - A text diagram in a code block where Mermaid does not render (terminal).
   - A calculation: a code block, one step per line, units kept.
   - Keep each to 4–8 boxes. Label arrows with verbs ("resamples", "binds", "inhibits").
   - Heavy flows: overview → zoom-ins.
4. **Key concepts:** 3–5 bullets. Each is `term — plain meaning — why it matters here`.
5. **The caveat** that would change the answer, in one sentence.
6. **One exam angle:** one way this gets asked that the user may not expect, with a one-line answer.
7. Science claim → the Claim / Evidence / Uncertainty / Unknown block.
8. Offer line: `→ L2 diagram · L3 lesson · L4 visual · quiz me · guide me`

Length: about 300–500 words plus the diagrams.
