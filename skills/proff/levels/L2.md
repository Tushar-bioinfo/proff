# L2 — one diagram plus the key concepts

1. **Predict first.** Ask one short prediction question about the concept. In a chat, show it first, then give the answer below a line, so the user can think before reading on. (This is not a mode. Do not wait.)
2. **Answer** in 2–4 STE sentences.
3. **One diagram.** Choose the form that shows the mechanism, not decoration:
   - Mermaid (`flowchart LR`, `sequenceDiagram`) where it renders (claude.ai, ChatGPT, GitHub, most IDEs).
   - A text diagram in a code block where Mermaid does not render (terminal).
   - Keep it to 4–8 boxes. Label arrows with verbs ("resamples", "binds", "inhibits").
4. **Key concepts:** 3–5 bullets. Each is `term — plain meaning — why it matters here`.
5. **The caveat** that would change the answer, in one sentence.
6. Science claim → the Claim / Evidence / Uncertainty / Unknown block.
7. Offer line: `→ L3 deck · quiz me · guide me`

Length: about 250–400 words plus the diagram.
