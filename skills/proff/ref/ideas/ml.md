Examples, not limits. Invent the visual that makes this idea land, and cover every important part.

## What to show
- Tensor shapes → input, operation, output with each dimension. Mark which axis changes and which stays.
- Train/validation/test → separate groups, then a leakage arrow. Mark the unit split and any shared donors.
- Loss curves → training and validation on shared axes. Mark the overfit point and chosen checkpoint.
- Decision boundary → movable parameter and predictions. Compare boundary changes; show one live error count.
- Attention → weighted lines from query to keys. Mark weights, their sum, and what the value aggregation produces.
- Embedding → scatter with direct labels. Compare neighbourhoods; state what distances do and do not mean.
- Confusion matrix → counts and class totals. Mark false positives/negatives and the metric denominator.
- Gradient descent → computed contour and successive positions. Mark slope, step size, and the change in loss.

## Plot styling
Use 4–6 ticks, axis labels at the ends, direct series labels, and units on axes. Compare on equal scales.
