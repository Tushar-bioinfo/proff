Examples, not limits. Invent the visual that makes this idea land, and cover every important part.

## What to show
- Sampling → one sample, repeated draws, then the spread of estimates. Mark the estimate and sample size.
- Null and tail → computed null curve with an observed statistic and shaded tail. Mark the hypothesis and tail probability.
- Interval coverage → many intervals against one fixed true value. Compare hits and misses; annotate repeated-sampling coverage.
- Regression → fitted line, residual distances, then an outlier. Compare the fit with and without it.
- Power → curves against effect size for several sample sizes. Mark the chosen threshold and design point.
- Multiple testing → null tests and false positives beside adjusted decisions. Show counts and the denominator.
- Prior to posterior → shared axes for prior, likelihood, posterior. Mark how evidence changes uncertainty.

## Plot styling
Use 4–6 ticks, axis labels at the ends, direct series labels, and units on axes. Compare on equal scales.
