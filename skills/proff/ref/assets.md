# Icons and images: sources and licences

Draw with the kit first. Use outside art only when a recognisable object helps (an instrument, an organ) and the kit cannot draw it simply. Record source and licence in an `info` sidebar or the page `foot`.

| Source | What | Licence (check per item) |
|---|---|---|
| Bioicons (bioicons.com) | lab and biology icons, SVG | per folder: CC0, CC BY, CC BY-SA, MIT; read the folder's licence |
| Servier Medical Art (smart.servier.com) | anatomy, cells, lab | CC BY 4.0; credit "Servier Medical Art". Its terms forbid automated bulk downloading, so fetch single files only when the user asks |
| SciDraw (scidraw.io) | neuroscience and lab drawings | CC BY 4.0 (most); credit the author |
| Reactome icon library | pathway and molecule icons | CC BY 4.0 |
| RCSB PDB images | protein structures | CC0 for structure images; cite the PDB ID |
| Wikimedia Commons | photos, diagrams | per file; many CC BY-SA (share-alike) |

Rules: put files in `<topic>/img/`; no text inside images (labels are kit text); never use an image whose licence you have not read this session; downloads need the user's approval.
