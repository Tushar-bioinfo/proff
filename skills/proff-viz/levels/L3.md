# L3: the full lesson, in text with ASCII figures

L3 is the deep version, written in the chat. Cover every part the reader needs. Use short sentences; leave nothing important out.
No HTML, no deck, no page: those are L4. Figures here are plain-text drawings in code blocks, so they read the same in a terminal, a chat, or a pasted note.

## 1. The write-up
Use these sections in order. Skip only what does not apply.
1. **Answer** — 2–4 sentences.
2. **What you need first** — 2–5 ideas: `term — plain meaning`.
3. **How it works** — the mechanism step by step, with an ASCII flowchart (below).
4. **Worked example** — real numbers, every step, units kept. Show the data and each step as an ASCII breakdown (below). Equations as $$..$$, then a "where" block: `symbol : meaning`, next line `e.g. value from this example`.
5. **Where it breaks** — assumptions and cases where the idea fails.
6. **Exam angles** — 4–6 unexpected questions with short answers. Try reversed cause/result, an edge case, changed numbers, confusable terms, design/data reading, or "why not X?".
7. **Do not confuse** — table: term · means · not the same as.
8. **Read next** — 3–5 search terms with what each teaches. Name sources from memory only when certain they exist; mark "from memory, not opened". DOI, page, or figure details require sources opened this session.
9. **Claim block** for science (see `SKILL.md`).

## 2. ASCII figures (2–4 per lesson, where a picture beats a sentence)
- **Flowchart** for a process or pipeline. Boxes in story order, arrows labelled with verbs. ≤ 8 boxes; a long process gets an overview, then one zoom-in.
```
 cells ──lysed──▶ RNA ──reverse-transcribed──▶ cDNA ──sequenced──▶ reads ──counted──▶ table
                                                                     │
                                                          one gene, one sample = one cell
```
- **Calculation breakdown** for any number: the small table, then one line per step, units kept, the result marked.
```
            S1     S2           step                         S1
 GeneA     120    300           N  = 120 + 30 + 850       = 1,000 reads
 GeneB      30     60           p  = 120 / 1,000          = 0.12
 GeneC     850    640           CPM = 0.12 × 10⁶          = 120,000   ◀ result
```
- **Sketch** of a shape or distribution only when the shape is the point (a skewed histogram, two overlapping groups, a strand with a cut site). Keep it ≤ 10 lines; label the axes.
- Rules: monospace width ≤ 90 characters; align columns; every number computed (use Python when a shell exists); no colour or emoji; a one-line caption under each figure saying what to look at.
